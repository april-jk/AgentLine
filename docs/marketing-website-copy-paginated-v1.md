# AgentLine 分页宣发文案方案（V1）

## 1. 目标与使用方式

这份文档用于先定文案、后做设计。
你可以直接按“页面 -> 区块 -> 文案”复制到网站，再逐段修改语气。

目标：
1. 保留 `yepanywhere` 那种“直接、可执行、低废话”的转化节奏。
2. 在 AgentLine 品牌下升级为“分页专题站”的叙事结构。
3. 每页都有锚点导航，便于手机端快速跳转与阅读。

---

## 2. 参考站点提炼（来自 yepanywhere）

参考结论（不是逐字复用）：
1. 首屏先给结果承诺，再给工作机制。
2. 用“价值卡片”快速解释为什么不是普通远程终端。
3. 在中段插入对比模块，建立类别认知。
4. 用截图和功能列表补证据。
5. 结尾用安装与 FAQ 降低决策成本。

可借鉴的文案方法：
1. 句式短，动词强：`Approve / Supervise / Unblock`。
2. 明确“你失去什么、你得到什么”：离开电脑不会中断，回到手机就能继续。
3. 信任声明放在功能区而不是埋在页脚：加密、官方 SDK、无账号依赖。

## 4. 跨页汇聚路径（Conversion Convergence）

目标：任何页面都能在 2 次点击内到达安装。

路径设计：
1. 首页 CTA：`立即开始` -> `/install`
2. 专题页 CTA：`查看真实使用方式` -> `/compare`，`开始安装` -> `/install`
3. 对比页 CTA：`我需要多会话监督` -> `/install`
4. 安装页 CTA：`启动后登录` -> `/remote`

每页底部统一收口文案：
`把等待代理，变成调度代理。` + `立即安装 AgentLine`

## 6. 统一文案规范（写作规则）

1. 一屏一个主结论，不在同屏讲两个核心卖点。
2. 先写“用户结果”，再写“技术机制”。
3. 每个区块最多一个长句，其余使用短句。
4. 功能描述避免形容词堆叠，优先“动作 + 收益”。
5. 每页至少一个“下一步动作”按钮，避免死角页面。
