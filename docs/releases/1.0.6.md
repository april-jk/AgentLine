# AgentLine 1.0.6 发布产物说明

这份文档记录 1.0.6 版本的本地打包命令，以及打包完成后应该去哪里找文件。

## 版本来源

- 根目录 `package.json` 的 `version` 是唯一发布版本源，当前为 `1.0.6`。
- Web/服务端/共享协议包：`packages/client`、`packages/server`、`packages/shared`、`packages/relay` 与根版本保持一致。
- RN 移动端：`packages/mobile-rn/package.json`、`packages/mobile-rn/app.json`、Android 原生配置、iOS 原生配置都与根版本保持一致。
- Electron 桌面端：`packages/desktop-electron/package.json` 与根版本保持一致。
- Device Bridge / Android device server：服务端 fallback、Android 设备服务版本名与根版本保持一致。

发布前先运行：

```bash
pnpm version:check
```

如果版本漂移，这个命令会直接报错。

## 发布前环境

所有命令都从仓库根目录执行。

- Node.js 20
- `pnpm 9.15.1`
- Android：JDK、Android SDK、Gradle 环境
- iOS：macOS、Xcode、CocoaPods、Apple 签名证书和 provisioning profile
- 桌面端：Electron Builder；Windows/Linux 跨平台打包可能还需要对应平台或额外系统工具

## Android

调试 APK：

```bash
pnpm dist:mobile-rn:android:debug-apk
```

产物位置：

- `packages/mobile-rn/android/app/build/outputs/apk/debug/app-debug.apk`

发布 APK：

```bash
pnpm dist:mobile-rn:android:release-apk
```

产物位置：

- `packages/mobile-rn/android/app/build/outputs/apk/release/app-release.apk`
- `packages/mobile-rn/android/app/build/outputs/native-debug-symbols/release/native-debug-symbols.zip`

Google Play AAB：

```bash
pnpm dist:mobile-rn:android:release-aab
```

产物位置：

- `packages/mobile-rn/android/app/build/outputs/bundle/release/app-release.aab`
- `packages/mobile-rn/android/app/build/outputs/native-debug-symbols/release/native-debug-symbols.zip`

注意：当前 Android release 配置仍使用 debug keystore 签名。正式上传 Google Play 前，需要在 Android Studio/Gradle 中配置生产签名，或改用目标账号的正式签名流程。

## iOS

模拟器 Release 构建：

```bash
pnpm dist:mobile-rn:ios:simulator
```

真机 Archive：

```bash
pnpm dist:mobile-rn:ios:archive
```

产物位置：

- `packages/mobile-rn/ios/build/archive/AgentLine-1.0.6.xcarchive`

生成 `.xcarchive` 后，可以用 Xcode Organizer 或 `xcodebuild -exportArchive` 导出签名后的 `.ipa`。`.ipa` 的最终位置取决于你选择的导出目录和 Apple 签名配置。

## macOS

```bash
pnpm dist:desktop-electron:mac
```

产物目录：

- `packages/desktop-electron/release/`

常见产物：

- `AgentLine Desktop-1.0.6-*-mac.zip`
- `AgentLine Desktop-1.0.6-*.dmg`
- 对应的 `.blockmap`

## Windows

```bash
pnpm dist:desktop-electron:win
```

产物目录：

- `packages/desktop-electron/release/`

常见产物：

- `AgentLine Desktop Setup 1.0.6.exe`
- `AgentLine Desktop 1.0.6.exe`
- Electron Builder 生成的 `.blockmap`

## Linux

```bash
pnpm dist:desktop-electron:linux
```

产物目录：

- `packages/desktop-electron/release/`

常见产物：

- `AgentLine Desktop-1.0.6*.AppImage`
- `agentline-desktop-1.0.6-*.deb` 或 Electron Builder 生成的等价 `.deb` 文件名

## 桌面端一次性打包

```bash
pnpm dist:desktop-electron:all
```

这个命令会顺序执行 macOS、Windows、Linux 三个平台打包。若某个平台因为系统依赖或签名环境失败，就在对应系统上单独运行该平台命令，产物目录仍然是：

- `packages/desktop-electron/release/`

## 建议的发布前检查

```bash
pnpm version:check
pnpm typecheck:desktop-electron
pnpm typecheck:mobile-rn
pnpm --filter @agentline/client build
pnpm --filter @agentline/client build:remote
```

Android/iOS 的完整原生打包还需要本机签名环境和平台工具链；如果只做发布前代码检查，优先跑上面的版本检查、类型检查和 Web/remote client 构建。
